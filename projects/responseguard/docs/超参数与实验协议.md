# ResponseGuard 超参数与实验协议

主实验配置保存于 [configs/sd35.json](../configs/sd35.json)，完整离线 smoke 使用 [configs/smoke.json](../configs/smoke.json)。下表给出可以直接启动实验的一组初值。文稿没有给出作者训练日志或验证集最优值，正式论文应报告经过验证集选择后实际运行的配置。

## 生成与优化

| 参数 | SD3.5 Medium 主实验 | CPU smoke | 设置依据 |
|---|---:|---:|---|
| 训练种子 | 17、42、73 | 同左 | 独立初始化适配器并洗牌。参考种子 2718、评测种子 31415 对全部方法固定 |
| 数据划分种子 | 1203 | 1203 | 对象、颜色和空间关系各取相邻两个词值组成块，按块划分。完整训练集覆盖全部原子概念 |
| 每轮完整组数 × 分支数 × 每分支图数 | 2 × 2 × 4 | 2 × 2 × 4 | 每次更新比较 2 个完整提示词对，共 16 张在线图 |
| 训练更新数 | 4,000 | 16 | 每次使用 2 对，每遍重新洗牌。主实验遍历 8,000 对一遍。smoke 遍历 8 对四遍，使各项计数预算能覆盖联合模型首次参考构建 |
| 图像分辨率、计算精度 | 512 × 512、BF16，适配器参数 FP32 | 64 × 64、FP32 | 512 用于控制多分支参考生成的成本 |
| 去噪步数，训练 / 评测 | 10 / 28 | 4 / 5 | 用较短轨迹收集训练样本，所有方法使用同一评测采样器 |
| CFG、随机流噪声幅度 | 4.5、0.55 | 几何模拟器无 CFG，噪声 0.45 | 同一对共享初始噪声，两个分支的探索噪声条件独立 |
| 文本长度上限 | T5 128 tokens | 结构化场景 | 固定每个 SD3 分支的条件编码预算 |
| LoRA 秩 / alpha / dropout | 16 / 16 / 0 | 4 / 4 / 0 | 主模型适配注意力的 Q、K、V 与输出投影，缩放比为 1 |
| AdamW 学习率 | 0.00001 | 0.004 | 主模型使用完整高斯转移密度，先从较小步长启动。模拟器是低维流模型 |
| AdamW 其余参数 | β₁ 0.9，β₂ 0.999，ε 1e−8，weight decay 0 | 同左 | 常数学习率，梯度范数上限 1.0 |
| PPO 裁剪范围、重放轮数 | 0.10、2 | 同左 | 实际逐步概率比在 0.9–1.1 裁剪，每次新采样只更新一次乘子 |
| 微批次、断点间隔 | 1 张、10 次更新 | 8 张、2 次更新 | 梯度在完整组上累积，减小显存占用 |
| 验证里程碑 | 62、125、250、500、1,000、2,000、4,000 次更新 | 1、2、4、8、16 次更新 | 按总更新数的 1/64、1/32、1/16、1/8、1/4、1/2 与全部取整，最低为 1，重复点合并 |
| Bootstrap 重采样 | 1,000 次，配对 95% 区间 | 200 次 | 内部测试按完整提示词对重采样，两方向和全部图像种子始终一起入样 |

## 锚点、投影与约束

| 参数 | 主实验 | 作用与数值解释 |
|---|---:|---|
| 每方向参考样本 / 独立有效率校准样本 / 最终评测样本 | 16 / 16 / 16 | 三组使用分离的随机流。smoke 为 8 / 8 / 16 |
| 语义、质量通过阈值 | 0.65、0.60 | 语义取五个原子分数的最小值。两项都通过才进入距离计算 |
| 最小双向参考间隔、允许退化量 | 0.25、0.08 | 前者过滤含混锚点，后者容许独立探索产生的小幅波动 |
| 每个语义方向最少匹配样本、投影秩上限 | 2、4 | 五个显式因素分别生成邻域干预。不足两个匹配样本的方向不进入 SVD，数值秩不足时自动降低 |
| 多样性保留比例 κ | 0.80 | 只惩罚有效图像残余距离低于参考距离 80% 的部分 |
| 有效率下界 | max(0.50, 参考校准有效率 − 0.10) | K=4 时，单张通过的组有效率为 0.25，必然承担有效率惩罚。校准 16 张时一个样本对应 0.0625 |
| 有效率惩罚权重 γ | 1.0 | 两个方向分别计算有效率平方短缺，再取平均 |
| 语义、条件多样性成本预算 | 0.025、0.025 | 单个锚点单方向超出允许间隔 0.32 时，对 K=4 组的语义成本贡献为 0.0256。两个方向都少 0.16 的有效率时，有效率项为 0.0256 |
| 乘子初始值、对偶学习率 | (0.20, 0.20)、(0.05, 0.05) | 按新采样组的平均原始成本减预算更新，再投影到非负区间 |
| 历史窗口、归一化尺度下限 | 256 个完整组、0.10 | 基线优先使用同一对的历史数据，稀疏时退回窗口总体。用当前乘子重新计算历史效用，尺度取过去组效用的总体标准差 |
| 偏好 / 质量 / 语义任务奖励权重 | 0.45 / 0.20 / 0.35 | 偏好用单图原始余弦，语义用所有原子满足度均值，系数和为 1 |
| Vendi 固定样本数 m | 4 | 各方法在共同满足条件的提示词上，从合格图像中按固定种子优先级取 4 张，同时报告覆盖率 |

语义成本使用逐种子的参考锚点指示量作为掩码，分母始终为每方向的 K。距离项要求参考与当前各有两张合格图像，并且测得局部语义方向。有效率项在每个提示词上均计算。历史基线、乘子和组优势在一次采样的全部 PPO 重放期间冻结。同一组所有分支共用一个优势。逐步裁剪在旧策略处具有对应的一阶梯度，多轮更新使用局部代理目标。

## 对照方法

| 方法 | 实现与超参数 |
|---|---|
| 冻结 SD3.5 | 使用相同初始噪声、采样器、步数和评测核验器 |
| Flow-GRPO | 按提示词标准化单图奖励，逐坐标平均对数密度，裁剪 ε=0.001，冻结参考 KL 系数 0.04 |
| DiverseGRPO | 使用 DreamSim 距离、组内高斯核谱聚类、按簇大小给探索奖励。K=4 时取 2 簇，带宽取非零距离中位数，奖励系数 0.7。前 4 个去噪步加均值差 Wasserstein 惩罚，本工程系数 0.04 |
| DRIFT | 每方向采 2K=8 图，按感知距离选择最集中的 K=4 图。条件嵌入加噪 η=0.05，退火区间 [0.4, 1.0]，按原嵌入均值和标准差重标定。按图平均组内平方距离，截断至 1.0，独立标准化后以 0.6 加入优势 |
| Pair-GRPO 扩散适配 | 将两个方向的 2K 个在线单图奖励共同标准化，复用扩散转移与参考 KL。原始 FocusDiff 使用自回归骨干与编辑图像，本试验使用同一 SD3 和成对文本 |
| 相同语义监督 | margin-supervised 直接将 0.20 × 自身与互斥要求的间隔加入单图奖励，再按提示词标准化 |
| 受控消融 | task-only、semantic、diversity、joint 构成 2 × 2。unprojected 去掉当前与参考距离的投影。per-prompt 使用按提示词标准化的单图奖励。训练命令的 --no-history 可单独关闭组级基线和缩放 |

对照方法移植到本项目的同一骨干、成对数据、任务奖励和优化循环。在线生成、筛掉的候选和额外参考前向都计入各自的成本。DiverseGRPO 与 DRIFT 在训练中使用 DreamSim，因此同时观察独立的 DINOv2-Base 辅助距离。[Flow-GRPO](https://arxiv.org/html/2505.05470v5) · [DiverseGRPO](https://arxiv.org/html/2512.21514) · [DRIFT](https://arxiv.org/html/2601.12401) · [FocusDiff](https://proceedings.mlr.press/v306/pan26b.html)

## 如何锁定正式超参数

1. 在验证集上用 audit 分别导出训练核验器和评测核验器的图片。人工填写语义与质量二值标签，用 calibrate 按平衡准确率拟合两套门槛。原有 0.65 和 0.60 是启动值。
2. 对预先固定的 32 对验证提示词运行 projection-audit。它在独立种子上测量干预方向投影后剩余的能量，从秩 1、2、4、5 中，取平均残余能量距最低值 0.05 以内的最小秩，并报告可计算覆盖率和低于有效率下界的参考提示词比例。覆盖不足时该命令保留缺失值。
3. 每种方法在同一批固定的 64 对验证提示上，比较学习率 5e−6、1e−5、2e−5，每个候选训练 250 次更新。预先设定选择顺序为先最小化相对参考的短缺，再最大化独立偏好分。PairSR、质量及有效率各容许下降 0.03，D_eff 保留目标为参考值的 0.80。受控消融沿用联合方法选出的学习率，方法级对照用各自的验证结果。
4. 固定最终配置后，以 17、42、73 三个种子完成训练，最后运行留出测试、GenEval 2、DeltaBench 和 200 条通用创作提示词。若需额外阈值敏感性分析，可在验证集比较 κ∈{0.7,0.8,0.9}、间隔容忍量∈{0.04,0.08,0.12} 或有效率松弛量∈{0.05,0.10,0.15}。这些网格是备选实验，交付的 smoke 仅执行了学习率搜索和投影秩检查。

```bash
python -m responseguard data --out data
python -m responseguard projection-audit --config configs/sd35.json --data data/val.jsonl --cache cache/refs --out runs/projection
python -m responseguard tune --config configs/sd35.json --data data --cache cache/refs --out runs/search
bash scripts/run_experiments.sh configs/sd35.json runs/study data cache/refs --selection runs/search/selection.json
```

训练与评测门槛分别校准后，可给 tune、study 或 projection-audit 传入 --eval-config 指定评测配置。主实验按冻结验证计划比较各方法，再从每个方法实际测得的检查点中选取未超同一成本上限的最后一点。初始冻结模型对应零训练成本。预算报告分别记录去噪样本前向数、实际前向调用数、核验问题数、偏好打分数及 CUDA 设备小时。公共基准或人工标注使用独立产物记录。

每条预算轴的共同上限取各方法最终累计成本的最小值，达到各方法首次实测训练检查点的最大成本后才进入共同区间。若区间为空，报告记录 `no_trained_overlap`，零计费的 CPU 设备小时轴记录 `unavailable`。主设置下联合模型首次使用新提示词对时，每次更新计费 8,640 个去噪样本前向，最便宜方法的最终上限估算为 3,840,000，故第 62、125、250 次更新都能在该上限内接受验证。设备小时取决于实测硬件。

按当前主配置，每对首次构建完整参考需生成 192 张图，含两方向主参考、八组其余因素干预和独立校准。8,000 对共需 1,536,000 张参考图，4,000 次更新另外在线生成 64,000 张。按 CFG 两分支、10 个去噪步与两轮重放，联合方法训练的理论计费量为 34,560,000 个去噪样本前向，含首次参考构建，评测另计。这是预算估算，实际设备小时从日志读取。共享磁盘缓存节省实际重算时间，每种方法独立核算一次其用到的参考成本。

## 公开基准与盲评

正式评测使用 BLIP-Large、DreamSim ensemble、DINOv2-Base 和 HPSv2.1。训练使用 BLIP-Base、DINOv2-Small 和 PickScore。两个语义核验器都属于 BLIP 家族，盲评与公开基准可用于进一步交叉核验。[HPSv2 官方实现](https://github.com/tgxs002/HPSv2) · [DreamSim 官方实现](https://github.com/ssundaram21/dreamsim)

```bash
python -m scripts.public_eval --study runs/study --data data --geneval-repo upstream/GenEval2 \
  --geneval-python /path/to/geneval-env/bin/python --delta-data upstream/deltabench.json \
  --delta-python /path/to/delta-env/bin/python --delta-revision "$DELTA_MODEL_COMMIT" --out runs/public
python -m responseguard blind --runs runs/study/flow-grpo/seed-42/eval runs/study/joint/seed-42/eval \
  --prompts 200 --raters 3 --out runs/blind
python -m responseguard blind-score --study runs/blind --out runs/blind/outcomes.json
```

public_eval 调用官方 GenEval 2 评分器，汇总 800 条提示词的 Soft-TIFA AM 和 GM。每条提示词先对其原子分数取算术或几何平均，再对提示词等权平均。按技能分层使用该技能的原子分数。DeltaBench 使用两方向完整问题清单，在独立环境用 Qwen3-VL 按正确答案打分，四张图组成一个评价单位。DELTA_MODEL_COMMIT 填入所用评测权重的完整提交号。[GenEval 2 评分代码](https://github.com/facebookresearch/GenEval2/blob/main/evaluation.py#L173-L178) · [DeltaBench 论文](https://proceedings.mlr.press/v306/pan26b.html)

通用创作评测每条提示词生成 16 张图。跨种子的条件距离和 Vendi 分别取所有参评方法、种子和冻结参考的共同可计算提示词，保存覆盖率、均值和样本标准差。配对差异的区间按参与该项对比的提示词或提示词对重采样。已有完整公开评测的原始分数、生成清单和原训练计划时，加 `--scores-only` 可离线重算汇总。

盲评将每位评审的无方法名图片和评分表输出到 forms，方法位置密钥保存在 private。评审对语义符合程度、视觉质量和组内合理多样性分别填 A、B 或 TIE。只有某个提示词同维度的全部指定评审完成后，汇总才纳入该项。未形成过半票时计平局。原稿划去的 FLUX.1-dev 与 ReNFT 是另列的扩展设想，当前研究配置以正文保留的 SD3.5 主实验为范围。
